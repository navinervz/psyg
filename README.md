# PsyG — فاز اول (فرانت‌اند)

سایت افیلیت رصد قیمت، ساخته‌شده روی Next.js 15 + Tailwind v4 + GSAP + Lenis.

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:3000`.

> اگر پوشه‌ی `node_modules` نصب نشده، دستور `npm install` را حتماً قبل از `npm run dev` اجرا کنید.

## متغیرهای محیطی

`.env.example` را به `.env.local` کپی کنید:

| متغیر | کاربرد |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | آدرس نهایی سایت؛ برای canonical، sitemap و OG |
| ~~`NEXT_PUBLIC_DIGIKALA_AFFILIATE_ID`~~ | **حذف شد.** در افیلیو هر لینک `affid` یکتا دارد، پس شناسه‌ی ثابتی وجود ندارد. لینک آماده در `affiliateUrl` هر محصول ذخیره می‌شود. |
| `N8N_SUBSCRIBE_WEBHOOK_URL` | وبهوک n8n برای ایمیل‌های «خبرم کن» (فاز ۲). اگر خالی باشد، ایمیل فقط لاگ می‌شود |

## لایه داده: سبک در برابر سنگین

دو ماژول داده داریم و تفکیکشان عمدی است:

| ماژول | محتوا | کجا استفاده شود |
|---|---|---|
| `lib/reference.ts` | دسته‌بندی، فروشگاه، ویژگی (چند کیلوبایت) | همه‌جا، از جمله کامپوننت‌های `"use client"` |
| `lib/data.ts` | کاتالوگ محصولات + مقاله‌ها (~۹۷ کیلوبایت) و هرچه از آن مشتق می‌شود | **فقط کامپوننت سروری** |

`lib/data` قابل tree-shake نیست، چون `alerts` را در سطح ماژول از روی
`products` می‌سازد. پس هر کامپوننت کلاینتی که از آن بخواند، کل کاتالوگ را
به مرورگر می‌فرستد. `HeaderActions` در همه‌ی صفحه‌ها رندر می‌شود و همین
اشتباه ۱۴ کیلوبایت به هر صفحه اضافه کرده بود.

**نکته‌ای که دو بار گولم زد:** مرز کلاینت زنجیره‌ای است. کامپوننتی که
`"use client"` ندارد، اگر از یک کامپوننت کلاینتی ایمپورت شود، خودش هم
کلاینتی می‌شود. راه فرار: داده را به‌صورت prop بده، یا فرزندان را
به‌عنوان `children` از یک کامپوننت سروری پاس بده (مثل
`Sidebar` → `RevealColumn`) — آن‌ها روی سرور رندر می‌مانند.

تست `routes.test.ts` این زنجیره را کامل دنبال می‌کند و اگر کاتالوگ از
هر مسیری به کلاینت برسد قرمز می‌شود.

## چیدمان: چرا هم rtl هست هم ltr؟

فایل رفرنس `psyg.jpg` چیدمان ستون‌ها را LTR گذاشته (لوگو چپ، سایدبار راست،
کارت ۰۱ چپ) ولی متن‌ها فارسی و راست‌چین‌اند. برای همین:

- `<html dir="rtl">` تا متن، اعداد و نقطه‌گذاری فارسی درست رندر شوند.
- روی کانتینرهای ساختاری (`main`، هدر، گرید کارت‌ها، سرچ‌بار) `dir="ltr"`.
- داخل هر ستون/کارت دوباره `dir="rtl"`.

اگر خواستید کل سایت RTL خالص شود، فقط همین `dir="ltr"`ها را بردارید.

## نکته‌های مهم

**توکن رنگ پس‌زمینه `night` است نه `base`.** چون Tailwind خودش `text-base` را
برای اندازه‌ی فونت رزرو کرده و تعریف `--color-base` باعث تداخل می‌شد.
برای متن تیره روی دکمه‌ی سبز از `text-night` استفاده کنید.

**هیچ عددی دو بار ذخیره نمی‌شود.** درصد تغییر قیمت، هشدارهای اخیر،
پیشنهادهای صفحه‌ی اصلی، سطح کاربر و زمان مطالعه‌ی مقاله‌ها همگی محاسبه
می‌شوند نه ذخیره. دلیلش یک باگ واقعی بود: هشدارها درصد هاردکد داشتند و
کاربر روی «۱۸٪ کمتر» کلیک می‌کرد ولی در صفحه‌ی محصول «۴٪» می‌دید. برای
سایتی که کل ارزشش دقت قیمت است، این یعنی بی‌اعتباری.

منطق مشتق‌سازی در `src/lib/derived.ts` است و تست‌های `derived.test.ts`
جلوی برگشتش را می‌گیرند.

**تصاویر محصولات هنوز اضافه نشده‌اند.** `ProductThumb` به‌جای آیکون شکسته،
آیکون همان دسته‌بندی را نشان می‌دهد. راهنمای نام‌گذاری در
`public/products/README.md`.

**فونت از Google Fonts نمی‌آید.** هم بیلد را به سرویس بیرونی گره می‌زد، هم
برای مخاطب ایرانی قابل اتکا نبود. `@font-face` خودمان تعریف شده و فایل‌ها از
`public/fonts` سرو می‌شوند — راهنما: `public/fonts/README.md`. اگر فایل‌ها
نباشند، مرورگر بی‌خطا به فونت سیستمی برمی‌گردد.

**علاقه‌مندی و پیگیری واقعاً ذخیره می‌شوند** (Zustand + localStorage) و در
`/account/favorites` و `/account/tracking` دیده می‌شوند. فاز اول حساب کاربری
ندارد؛ در فاز ۲ فقط لایه‌ی persist با API عوض می‌شود.

## لایه‌ی داده و فاز ۲

`StoreAdapter` (در `src/lib/adapters/types.ts`) قرارداد واحد همه‌ی فروشگاه‌هاست.
الان فقط `mockAdapter` وجود دارد که از JSON محلی می‌خواند.

برنامه‌ی همکاری در فروش دیجی‌کالا **لینک‌محور** است و فید عمومی محصول ندارد؛
به همین دلیل دو مسئولیت جدا شده‌اند:

1. `toAffiliateUrl` — ساخت لینک ترک‌دار (نیاز به شناسه ناشر).
2. `fetchProduct` / `fetchPriceHistory` — جمع‌آوری قیمت، که در فاز ۲ توسط
   ورک‌فلوهای n8n انجام و در دیتابیس ذخیره می‌شود.

با این جداسازی، سوئیچ از mock به دیتای واقعی هیچ تغییری در کامپوننت‌ها لازم ندارد.

## انیمیشن‌ها

- اسکرول نرم: `LenisProvider` که RAF آن به `gsap.ticker` وصل است.
- ورود سکشن‌ها: `useRevealOnScroll` روی فرزندانِ `.will-reveal`.
- کارت‌ها: ورود سه‌بعدی + تیلت هاور با `gsap.quickTo`.
- اسپارک‌لاین: کشیده‌شدن مسیر با `stroke-dasharray` (بدون نیاز به DrawSVG).
- تیتر هیرو: تقسیم کلمات دستی (بدون وابستگی به پلاگین SplitText).
- همه‌جا `prefers-reduced-motion` رعایت شده.

## دکمه خرید و لینک افیلیت

همه‌ی دکمه‌های «خرید» به `/go/[productId]` می‌روند، نه مستقیم به فروشگاه. دلیلش:

1. لینک افیلیت فقط در یک تابع ساخته می‌شود (`toAffiliateUrl`).
2. کلیک‌ها قابل شمارش‌اند (فاز ۲: ارسال به n8n).
3. اگر ساختار لینک عوض شد، فقط آداپتور تغییر می‌کند.
4. لینک‌ها `rel="nofollow sponsored"` دارند و `/go/` در robots مسدود است —
   الزام گوگل برای لینک‌های کمیسیونی.

## قدم بعدی

۱. **مقاله‌های مجله را بنویس.** الان فقط عنوان و خلاصه دارند؛ برای تایید

   `docs/digikala-affiliate-guide.md`
۲. تصاویر محصولات را در `public/products` بگذار.
۳. ارتقای `RobotMascot` از SVG به Three.js (R3F + Bloom) با همان API فعلی —
   `HeroSection` نیازی به تغییر ندارد.
