# کارهایی که باید خودت انجام دهی — قدم به قدم

این سند فرض می‌کند هیچ چیزی از قبل نمی‌دانی. هر دستور را **دقیقاً** همان‌طور
که نوشته شده کپی کن. بعد از هر مرحله نوشته‌ام «چه باید ببینی» — اگر چیز
دیگری دیدی، همان را برایم بفرست و ادامه نده.

**قانون کلی:** هیچ‌کدام از این کارها برگشت‌ناپذیر نیست، جز جایی که صراحتاً
هشدار داده‌ام. اگر جایی گیر کردی، متوقف شو و بپرس. حدس نزن.

---

## ۰. قبل از هر چیز — ترمینال را باز کن

روی ویندوز:

۱. کلید `Win` را بزن.
۲. تایپ کن `powershell`.
۳. روی **Windows PowerShell** کلیک کن.

یک پنجرهٔ آبی/مشکی باز می‌شود. حالا برو داخل پوشهٔ پروژه:

```powershell
cd C:\Users\NAVIX\OneDrive\Desktop\psyg
```

**چه باید ببینی:** خط ابتدای ترمینال به
`PS C:\Users\NAVIX\OneDrive\Desktop\psyg>` تغییر کند.

> اگر خطای `Cannot find path` دیدی یعنی مسیر پوشه فرق دارد. در فایل‌اکسپلورر
> پوشهٔ psyg را باز کن، روی نوار آدرس کلیک کن، مسیر را کپی کن و به‌جای مسیر
> بالا بگذار.

## ۱. تست و بیلد — مهم‌ترین مرحله

من چند فایل را تغییر داده‌ام ولی محیط من امکان اجرای تست نداشت. این مرحله
تایید می‌کند که چیزی نشکسته.

> **مهم — روی این ویندوز `npm` را با `npm.cmd` بزن.**
> ویندوز به‌صورت پیش‌فرض اجازه‌ی اجرای اسکریپت‌های PowerShell را نمی‌دهد و
> `npm` روی ویندوز یک اسکریپت PowerShell است، پس خطای
> `running scripts is disabled on this system` می‌گیری. `npm.cmd` همان
> برنامه است ولی این محدودیت شاملش نمی‌شود — و این‌طوری لازم نیست تنظیم
> امنیتی سیستم را دست بزنی.

### ۱.۱ اول وابستگی‌ها را مطمئن شو

```powershell
npm.cmd install
```

**چه باید ببینی:** چند خط لاگ و در آخر چیزی شبیه
`added 0 packages ... found 0 vulnerabilities`. اگر عدد `vulnerabilities`
بزرگ‌تر از صفر بود، خروجی را برایم بفرست ولی ادامه بده.

### ۱.۲ تست‌های سریع

```powershell
npm.cmd run test
```

این دو کار می‌کند: بررسی تایپ‌های TypeScript، و اجرای تست‌های واحد.

**چه باید ببینی:** در انتها خطی شبیه:

```
# pass 116
# fail 0
```

**اگر `fail` صفر نبود:** کل خروجی را کپی کن و برایم بفرست. کاری نکن.

**اگر خطای `spawn npx ENOENT` دیدی:** این باگ قدیمی ویندوز است که قبلاً حل
شده؛ اگر برگشت، به من بگو.

### ۱.۳ تست کامل با بیلد

این یکی طولانی‌تر است (حدود ۲ تا ۵ دقیقه). صبر کن تا تمام شود.

```powershell
npm.cmd run test:all
```

این علاوه بر بالا، سایت را کامل می‌سازد و ۱۲۱ تست e2e را روی نسخهٔ ساخته‌شده
اجرا می‌کند.

**چه باید ببینی:** در انتها دوباره `# fail 0`.

**اگر قرمز شد:** خروجی را برایم بفرست. مخصوصاً اگر جایی کلمهٔ
`Type error` یا `429` دیدی — این دو مستقیم به تغییرات من مربوط‌اند.

### ۱.۴ نگاه چشمی به سایت روی کامپیوتر خودت

```powershell
npm.cmd run dev
```

**چه باید ببینی:** خطی شبیه `- Local: http://localhost:3000`.

حالا مرورگر را باز کن و برو به `http://localhost:3000`.

بعد این تست ریسپانسیو را انجام بده:

۱. کلید `F12` را بزن (ابزار توسعه‌دهنده باز می‌شود).
۲. کلیدهای `Ctrl + Shift + M` را با هم بزن (حالت موبایل).
۳. بالای صفحه یک نوار می‌آید که می‌توانی عرض را عوض کنی. این عددها را
   یکی‌یکی امتحان کن و در هرکدام تا پایین صفحه اسکرول کن:

   | عرض | چه چیزی را چک کن |
   |---|---|
   | ۳۲۰ | هدر جا شده؟ نوار اسکرول افقی پایین صفحه ظاهر نشده؟ |
   | ۳۷۵ | قیمت کارت‌ها کامل دیده می‌شود؟ |
   | ۷۶۸ | تیتر «دنبال بهترین فرصت خرید هستی؟» و ربات کنار هم جا شده‌اند؟ |
   | ۱۰۲۴ | کارت‌های «بهترین فرصت‌ها» چهارتایی‌اند و محتوایشان بریده نیست؟ |
   | ۱۲۸۰ | سایدبار (پروفایل و خبرم کن) به سمت راست رفته و کارت‌ها شش‌تایی شده‌اند؟ |
   | ۱۹۲۰ | همه‌چیز وسط صفحه و مرتب است؟ |

۴. روی هرکدام که ایراد داشت، `Ctrl + Shift + S` بزن تا اسکرین‌شات بگیرد،
   یا با `Win + Shift + S` از صفحه عکس بگیر و برایم بفرست.

برای بستن سرور، در ترمینال `Ctrl + C` بزن و بعد `y` و `Enter`.

## ۴. تنظیم کلادفلر — دو کار

### ۴.۱ خاموش کردن robots.txt مدیریت‌شده

**چرا:** الان کلادفلر یک `robots.txt` خودش را بالای فایل ما تزریق می‌کند و
دو گروه `User-agent: *` می‌سازد. بعضی خزنده‌ها فقط اولی را می‌خوانند، و آن
اولی `/go/` را نبسته — یعنی مسیر لینک‌های افیلیت قابل خزیدن می‌شود. جزئیات
در `docs/audit-2026-08.md` بخش ۲.۳.

مراحل:

۱. برو به `https://dash.cloudflare.com` و وارد شو.
۲. از فهرست دامنه‌ها روی **psygstore.shop** کلیک کن.
۳. از منوی سمت چپ، **AI Crawl Control** را باز کن.
   (اگر این اسم را ندیدی، دنبال **Bots** یا **Security → Bots** بگرد.)
۴. گزینه‌ای به اسم **Managed robots.txt** یا **Add Cloudflare's managed
   robots.txt entries** پیدا کن.
۵. آن را **خاموش** کن.
۶. تغییر را ذخیره کن.

**چطور تایید کنی که درست شد:** چند دقیقه صبر کن، بعد در مرورگر برو به
`https://psygstore.shop/robots.txt`. باید فقط این را ببینی و نه چیز دیگر:

```
User-Agent: *
Allow: /
Disallow: /go/
Disallow: /search
Disallow: /api/
Disallow: /account/

Sitemap: https://psygstore.shop/sitemap.xml
```

اگر هنوز متن طولانی انگلیسی بالایش بود، از پنل کلادفلر
**Caching → Configuration → Purge Everything** را بزن و دوباره چک کن.

> **تصمیم با توست:** بلوک کلادفلر خزنده‌های هوش مصنوعی (`GPTBot`،
> `ClaudeBot`، `Google-Extended` و…) را هم می‌بندد. با خاموش کردنش، آن‌ها
> باز می‌شوند. برای سایتی که تازه می‌خواهد دیده شود، باز بودن معمولاً به
> نفع است — ولی این انتخاب توست، نه یک اشکال فنی.

### ۴.۲ بررسی حالت SSL

۱. در همان داشبورد، **SSL/TLS → Overview**.
۲. حالت باید **Full (strict)** باشد.

اگر روی `Flexible` بود، **عوضش نکن** بدون اینکه اول به من بگویی — با
Cloudflare Tunnel رفتار متفاوتی دارد و ممکن است سایت موقتاً بالا نیاید.

## ۵. تایید نهایی روی سایت زنده

بعد از دیپلوی، به سرور وصل شو (`ssh -p 9011 root@2.58.172.224`) و این دو
دستور را بزن.

### ۵.۱ هدرهای امنیتی

```bash
curl -sI https://psygstore.shop | grep -iE 'strict-transport|x-frame|x-content|referrer|permissions'
```

**چه باید ببینی:** پنج خط، شامل:

```
strict-transport-security: max-age=31536000
x-frame-options: SAMEORIGIN
x-content-type-options: nosniff
referrer-policy: strict-origin-when-cross-origin
permissions-policy: camera=(), microphone=(), geolocation=(), interest-cohort=()
```

اگر `strict-transport-security` نبود، یعنی بیلد جدید بالا نیامده — مرحلهٔ
۳.۳ را دوباره بزن.

### ۵.۲ محدودیت نرخ

```bash
for i in $(seq 1 14); do
  curl -s -o /dev/null -w "%{http_code} " -X POST https://psygstore.shop/api/subscribe \
    -H 'Content-Type: application/json' -d '{"email":"a@b.com"}'
done; echo
```

**چه باید ببینی:** ده تا `200` و بعد چند تا `429`. مثلاً:

```
200 200 200 200 200 200 200 200 200 200 429 429 429 429
```

اگر همه‌اش `200` بود یعنی middleware اجرا نمی‌شود — به من بگو.
