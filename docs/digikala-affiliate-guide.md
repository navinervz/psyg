# راهنمای پابلیش سایت و ثبت رسانه در همکاری در فروش دیجی‌کالا

مسیر کامل از «سایت روی لپ‌تاپ من است» تا «کمیسیون به حسابم واریز شد».

> این سند بر اساس اطلاعات عمومی منتشرشده تا تیر ۱۴۰۵ نوشته شده. جزئیات پنل
> ممکن است تغییر کرده باشد؛ ملاک نهایی همان چیزی است که در
> `affiliate.digikala.com` می‌بینی.

---

## ⚡ وضعیت امروز — مرحله‌های ۱ تا ۴ تمام شده‌اند

| مرحله | وضعیت |
|---|---|
| دامنه | ✅ `psygstore.shop` |
| ایمیل دامنه‌ای | ✅ `info@psygstore.shop` روی Cloudflare Email Routing، تست‌شده |
| میزبانی + SSL | ✅ سرور اختصاصی + Cloudflare Tunnel |
| `NEXT_PUBLIC_SITE_URL` | ✅ ست شده — sitemap آدرس‌های واقعی دارد نه localhost |
| صفحه‌های درباره / تماس / حریم خصوصی | ✅ |
| افشای رابطه‌ی افیلیت | ✅ در صفحه اصلی، فرصت‌ها، درباره و صفحه محصول |
| مقاله‌های مجله | ✅ چهار مقاله‌ی کامل، هرکدام بالای ۳۰۰ کلمه |
| موبایل | ✅ از ۳۲۰ تا ۱۹۲۰ پیکسل تست‌شده |
| sitemap و robots | ✅ |
| هدرهای امنیتی | ✅ هر پنج تا شامل HSTS |

**اینماد لازم نیست.** شرطش این است که سایت فروشگاهی باشد و خرید و فروش
واقعی در آن انجام شود؛ سای‌جی چیزی نمی‌فروشد. مهم‌تر اینکه همکاری در فروش
دیجی‌کالا هم اینماد نمی‌خواهد.

**تنها ضعف باقی‌مانده:** داده‌ی محصولات هنوز نمونه است — قیمت‌ها و شناسه‌های
`dkp` واقعی نیستند. یعنی دکمه‌ی «خرید» به صفحه‌ای می‌رود که ممکن است باز
نشود. اگر کارشناس روی یک محصول کلیک کند و به خطا برسد، احتمال رد شدن
هست. این را قبل از ثبت رسانه در نظر بگیر.

## چرا باید اول پابلیش کنی؟

دیجی‌کالا رسانه را بررسی می‌کند، نه ایده را. کارشناس باید بتواند سایت را باز
کند و ببیند. پس ترتیب اجباری این است:

```
دامنه → هاست → ایمیل دامنه‌ای → محتوا → ثبت رسانه → تایید → لینک‌ساز
```

---

## مرحله ۱ — دامنه

یک دامنه‌ی `.ir` یا `.com` بگیر (مثلاً `psyg.ir`).

- `.ir` از [ای‌ران‌نیک](https://www.nic.ir) یا نمایندگی‌ها، سالانه ارزان‌تر است.
- برای پرداخت ریالی و پشتیبانی فارسی، ثبت از نمایندگی داخلی راحت‌تر است.

**نکته‌ی مهم:** نام دامنه را با نام رسانه‌ای که ثبت می‌کنی یکی بگیر.

---

## مرحله ۲ — ایمیل روی دامنه (این مرحله را رد نکن)

برای احراز مالکیت سایت، **ایمیل پروفایل تو در پنل دیجی‌کالا باید با دامنه‌ی
سایت یکی باشد.** یعنی `areszamani@outlook.com` کار نمی‌کند؛ به چیزی مثل
`info@psyg.ir` نیاز داری.

گزینه‌ها:

| روش | هزینه | توضیح |
|---|---|---|
| ایمیل سرویس هاست | معمولاً رایگان با هاست | ساده‌ترین راه؛ اکثر هاست‌های ایرانی cPanel با ایمیل نامحدود می‌دهند |
| Zoho Mail | پلن رایگان دارد | ۵ کاربر روی دامنه‌ی اختصاصی، بدون نیاز به هاست |
| Google Workspace | ماهانه دلاری | پرداخت از ایران دردسر دارد |

**پیشنهاد:** اگر هاست ایرانی می‌گیری، همان ایمیل هاست کافی است.

---

## مرحله ۳ — میزبانی سایت

سایت Next.js است، پس دو مسیر داری:

### الف) Vercel (ساده‌ترین)

```bash
npm i -g vercel
vercel --prod
```

بعد دامنه را در پنل Vercel وصل کن.
**اما:** دسترسی Vercel از ایران گاهی محدود است و ممکن است کاربر ایرانی
سایت را باز نکند. برای رسانه‌ای که مخاطبش ایرانی است ریسک دارد.

### ب) سرور یا هاست ایرانی (پیشنهاد من)

یک VPS ایرانی (آروان، ابرآسیا، پارس‌پک و مشابه) با Node.js:

```bash
npm run build
npm run start   # روی پورت 3000
```

بعد Nginx را جلویش reverse proxy کن و SSL رایگان Let's Encrypt بگیر.

اگر با سرور راحت نیستی، بگو تا فایل‌های `Dockerfile` و کانفیگ Nginx را
هم برایت بنویسم.

## مرحله ۴ — قبل از ثبت، سایت را قابل قبول کن

رسانه‌ای که محتوا ندارد رد می‌شود. قبل از ارسال درخواست، این‌ها را داشته باش:

- [ ] صفحه‌ی «درباره ما» پر و واقعی — ✅ ساخته شده
- [ ] صفحه‌ی «تماس با ما» با ایمیل دامنه‌ای — ✅ ساخته شده (ایمیل را عوض کن)
- [ ] صفحه‌ی «قوانین و حریم خصوصی» — ✅ ساخته شده
- [ ] افشای شفاف رابطه‌ی افیلیت — ✅ کامپوننت `AffiliateNotice`
- [ ] حداقل چند مطلب واقعی در مجله (فعلاً فقط عنوان و خلاصه دارند — **متن کاملشان را بنویس**)
- [ ] سایت روی موبایل درست باز شود — ✅
- [ ] `sitemap.xml` و `robots.txt` — ✅ خودکار تولید می‌شوند
- [ ] بدون خطای ۵۰۰ و بدون صفحه‌ی خالی

~~ضعف فعلی: مجله فقط عنوان دارد~~ — **این برطرف شد.** چهار مقاله‌ی کامل
نوشته شده و تستی هم هست که اگر کسی متن جای‌نگهدار یا مقاله‌ی زیر ۳۰۰ کلمه
اضافه کند، قرمز می‌شود.

**ضعف واقعی امروز داده‌ی محصولات است**، نه محتوا. جزئیاتش بالای همین سند.

## مرحله ۵ — ثبت‌نام و افزودن رسانه

۱. به [affiliate.digikala.com](https://affiliate.digikala.com) برو و ثبت‌نام کن.
۲. در **پروفایل**، ایمیل را همان `info@psyg.ir` بگذار.
۳. اطلاعات هویتی و شماره‌ی شبا را کامل کن (برای تسویه لازم است).
۴. روی **«افزودن رسانه»** بزن، نوع را «سایت» انتخاب کن و آدرس کامل
   (`https://psyg.ir`) را وارد کن.
۵. ارسال کن.

## مرحله ۶ — انتظار برای تایید

- بررسی معمولاً **۲۴ تا ۴۸ ساعت** طول می‌کشد.
- نتیجه از طریق ایمیل اطلاع داده می‌شود.
- اگر رد شد، دلیلش را برطرف کن و **دوباره ارسال کن** — محدودیتی در تعداد
  درخواست نیست.

**شایع‌ترین دلایل رد شدن:**

| دلیل | راه‌حل |
|---|---|
| ایمیل با دامنه یکی نیست | ایمیل دامنه‌ای بساز و در پروفایل عوض کن |
| سایت محتوای کافی ندارد | مقاله‌های مجله را کامل کن |
| سایت بالا نمی‌آید یا SSL ندارد | هاست و گواهی SSL را چک کن |
| صفحه‌ی تماس/درباره ندارد | ✅ داری |

## مرحله ۷ — بعد از تایید: لینک‌ساز

در پنل، بخش **«مدیریت لینک‌ها»** لینک ترک‌دار می‌سازد.

یک محصول را دستی لینک بساز و **ساختار خروجی را ببین** — آنجا می‌فهمی
پارامتر ردیابی چه نامی دارد. بعد همان را در این فایل بگذار:

```
src/lib/adapters/mock.ts  →  toAffiliateUrl()
```

الان کد این‌طور است:

```ts
const url = new URL(productUrl);
url.searchParams.set("aff", affiliateId);   // ← نام پارامتر را با چیزی که پنل داد عوض کن
return url.toString();
```

و شناسه را در `.env.local` بگذار:

```
NEXT_PUBLIC_DIGIKALA_AFFILIATE_ID=شناسه‌ای که پنل داد
NEXT_PUBLIC_SITE_URL=https://psyg.ir
```

از آن لحظه، همه‌ی دکمه‌های «خرید» در سایت خودکار لینک ترک‌دار می‌سازند —
چون همه از مسیر `/go/[id]` عبور می‌کنند و آن هم از همین یک تابع استفاده می‌کند.

## مرحله ۸ — کمیسیون و تسویه

- **درصد کمیسیون:** بسته به دسته‌ی کالا بین **۰.۵٪ تا ۱۰٪** متغیر است.
- **نکته‌ی مهم:** اگر کاربر از لینک تو وارد دیجی‌کالا شود ولی **کالای دیگری**
  بخرد، باز هم کمیسیون آن خرید به تو تعلق می‌گیرد.
- سیستم درآمد را خودکار محاسبه می‌کند و داده‌ها طی حدود **سه روز کاری**
  بررسی می‌شوند.
- پایان هر ماه گزارش مالی در پنل نمایش داده می‌شود.
- از بخش **«امور مالی»** درخواست تسویه می‌دهی.
- **۲۰٪ از کمیسیون بابت مالیات و حق بیمه کسر می‌شود** — این را در محاسبه‌ی
  درآمدت لحاظ کن.

## مرحله ۹ — بعد از دیجی‌کالا

وقتی دیجی‌کالا راه افتاد، منطق برای بقیه یکسان است. برای هر فروشگاه جدید فقط
یک فایل در `src/lib/adapters/` بساز که `StoreAdapter` را پیاده کند و در
`src/lib/adapters/index.ts` ثبتش کن. هیچ کامپوننتی تغییر نمی‌کند.

پلتفرم‌های بعدی که ارزش بررسی دارند: افیلیو، دیجی‌استایل، تکنولایف و ترب.
