# فونت‌های سایت

هر دو فونت اینجا هستند و سایت به هیچ سرویس بیرونی (مثل Google Fonts) وصل
نیست — هم بیلد را به جای دیگری گره نمی‌زند، هم برای مخاطب ایرانی قابل
اتکاتر است.

| فایل | فونت | کجا استفاده می‌شود |
|---|---|---|
| `BYekan.woff2` | B Yekan+ | تمام متن سایت |
| `AGhasem.woff2` | A Ghasem | فقط نام برند «سای‌جی» |

## دو نکته که موقع تغییر فونت باید بدانی

**۱. آقاسم هیچ حرف لاتینی ندارد.**
جدول کاراکترهایش فقط عربی/فارسی و ارقام است (۲۸۸ گلیف). به همین دلیل نام
برند به فارسی نوشته می‌شود: «سای‌جی». اگر روزی خواستی «PsyG» لاتین را با
این فونت بنویسی، مرورگر بی‌صدا به فونت دیگری برمی‌گردد و اصلاً متوجه
نمی‌شوی.

در `globals.css` روی این فونت `unicode-range` گذاشته شده تا مرورگر برای
متن لاتین اصلاً سراغش نرود و بی‌خود دانلودش نکند.

**۲. هر دو فونت فقط یک وزن دارند (Regular).**
عمداً فقط `font-weight: 400` اعلام شده. اگر بازه‌ی `100 900` اعلام شود،
مرورگر فکر می‌کند همه‌ی وزن‌ها پوشش داده شده‌اند و `font-bold` و
`font-extrabold` هیچ تفاوتی نمی‌کنند — یعنی کل سلسله‌مراتب بصری سایت از
بین می‌رود. با اعلام تک‌وزن، مرورگر خودش ضخیم‌سازی می‌کند.

اگر نسخه‌ی چندوزنی این فونت‌ها را پیدا کردی، برای هر وزن یک بلوک
`@font-face` جدا اضافه کن — نتیجه‌اش از ضخیم‌سازی مرورگر تمیزتر است.

## تبدیل فونت جدید

فایل‌های اصلی TTF بودند و به woff2 تبدیل شدند (۲۲۹ → ۶۵ و ۳۴ → ۱۲
کیلوبایت). برای فونت جدید:

```bash
pip install "fonttools[woff]" brotli
python3 -c "
from fontTools.ttLib import TTFont
f = TTFont('input.ttf'); f.flavor = 'woff2'; f.save('output.woff2')
"
```

بعد در `src/styles/globals.css` بلوک `@font-face` مربوطه را به‌روز کن.
